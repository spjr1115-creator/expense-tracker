# Expense Tracker

Responsive personal finance app for tracking expenses, managing budgets, and visualizing monthly spending.

## Overview

Expense Tracker is a full-featured personal finance web application built to help users manage their personal income and expenditures. The app provides user authentication, category-based expense recording, monthly budget management, and interactive charts for spending visualization.

## Key Features

- **User Authentication**: Secure sign-in and account registration powered by Firebase Authentication.
- **Income & Expense Logging**: Record timestamped transactions with custom category selection.
- **Budget Management**: Set and monitor category spending thresholds.
- **Interactive Analytics**: Visual spending breakdowns and charts using Chart.js.
- **Cloud Synchronization**: Cloud Firestore data storage for cross-device access.

## Tech Stack

- **Frontend**: JavaScript, HTML5, CSS3, Chart.js
- **Backend & Cloud**: Firebase Authentication, Cloud Firestore
- **Deployment**: GitHub Pages
