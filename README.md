## ✨ Overview

**Expense Tracker** is a full-featured personal finance web application designed to make everyday money management simple, visual, and intuitive.

The application allows users to record their income and expenses, organize transactions into categories, monitor their financial balance, analyze spending patterns, and manage monthly budgets.

The project uses **Firebase Authentication and Cloud Firestore** to provide user authentication and persistent cloud-based data storage.

> 🎯 Built with a focus on **clean UI, responsive design, real-world functionality, and practical frontend development.**
